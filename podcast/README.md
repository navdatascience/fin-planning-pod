# Fin Planning Pod — Daily Podcast

A daily 4–5 minute podcast series built from the Fin Planning Pod library in this repo.
Each episode profiles one person/video from `spreadsheets/` and `data/extractions.json`:
their income breakdown, post-tax take-home, responsible + bonus spending, monthly investments,
savings spent, and current portfolio — plus the 3–4 lessons worth copying.

- Episodes: `podcast/episodes/ep<nnn>-<slug>.mp3`
- Notes: `podcast/notes.md`
- Transcripts (scripts): `podcast/transcripts/`
- RSS feed (podcast apps): `podcast/feed.xml` in this repo, canonical feed at https://muse.ai/podcasts/feed/650408721490907/b701f53b-0e19-4b97-acca-4e857fd47610
- Hosts: Mimi and Alex
- Rotation rule: one new source video per episode, never repeating a video already covered (see notes.md); videos added by the weekly library run join the rotation.
